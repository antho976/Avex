Noto Sans Medium and Noto Sans Mono Regular, subset to printable ASCII plus `×` with
`pyftsubset --unicodes="U+0020-007E,U+00D7"` so the vignettes render in the same faces on every
machine. They stand in for Android's own sans and monospace, which is what the cards sit among.
